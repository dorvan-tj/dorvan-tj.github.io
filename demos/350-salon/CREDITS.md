# Источники фотографий — демо «Iris» ($350)

Все фотографии — **временные**, с бесплатного сайта Unsplash (лицензия Unsplash: можно использовать
бесплатно, в том числе в коммерческих проектах; указывать автора не обязательно, но приятно).
Авторов снимков я автоматически не определял: сайт Unsplash закрыт для программ, поэтому фото найдены через открытый список ссылок.
Если понадобится указать автора, снимок можно найти на unsplash.com по описанию. В списке ниже — прямые адреса картинок.
Утром их заменит ИИ (см. `images-to-replace.md`), после замены этот файл можно удалить.
