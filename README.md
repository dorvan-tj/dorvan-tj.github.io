# Dorvan — сайт-портфолио

Студия сайтов для малого бизнеса в Душанбе. Живой адрес: https://dorvan.pro/

Контакты: Telegram [@dorvan_tj](https://t.me/dorvan_tj), Instagram [@dorvan.tj](https://www.instagram.com/dorvan.tj/).

## Что здесь лежит

- `index.html`, `css/`, `js/`, `assets/` — сайт-портфолио: HTML, CSS и немного JavaScript, без сборки. Три языка: русский, английский и таджикский (бета, тексты в `js/tj.js`). Настройки (контакты, число мест в акции, курс сомони) — `js/config.js`; отзывы клиентов — `js/reviews.js`; работы в блоке «Все работы» — `js/works.js` (одна запись = одна карточка, с образцом внутри файла).
- `demos/` — 14 демо: сайты по ступеням цены ($20, $40, $70, $100, $200, $350) и страница-показ Telegram-бота для клиентов. Демо-админки (ОТАШ, Nesta, Iris) и бот — это модули, которые добавляются к любому сайту (сайт ОТАШ вместе с его админкой — ступень $150 «Вау + админка»); они работают только в браузере посетителя. Открываются из блоков «Сколько стоит сайт», «Модули» и «Пакеты».
- `melty-bakery/`, `velora-clinic/` — ранние концепты.

Все компании, адреса, телефоны, цены и отзывы в демо вымышлены, на страницах они подписаны «Концепт».
