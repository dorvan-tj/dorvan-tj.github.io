# Dorvan — сайт студии

Студия сайтов и ботов для малого бизнеса в Душанбе. Живой адрес: https://dorvan.pro/

Контакты: Telegram [@dorvan_tj](https://t.me/dorvan_tj), Instagram [@dorvan.tj](https://www.instagram.com/dorvan.tj/).

## Что здесь лежит

- `index.html`, `css/`, `js/`, `assets/` — главная страница студии: HTML, CSS и немного JavaScript, без сборки. Настройки (контакты, число мест в акции) — `js/config.js`.
- `wow/` — страница «прокрутка = видео».
- `katalog/`, `zapis/` — служебные страницы воронки студии.
- `demos/`, `pearlia-dental/`, `clarus-medcenter/`, `selene-beauty/` — демо-сайты и концепты. Все компании, адреса, телефоны и отзывы в них вымышлены, на страницах они подписаны «Концепт».
- `melty-bakery/` — только переадресация на настоящий сайт клиента https://melty-bakery.shop/.
