# Dorvan — сайт-портфолио

Студия сайтов для малого бизнеса в Душанбе. Живой адрес: https://dorvan-tj.github.io/

Контакты: Telegram [@dorvan_tj](https://t.me/dorvan_tj), Instagram [@dorvan.tj](https://www.instagram.com/dorvan.tj/).

## Что здесь лежит

- `index.html`, `css/`, `js/`, `assets/` — сайт-портфолио: HTML, CSS и немного JavaScript, без сборки. Два языка (русский и английский).
- `demos/` — 13 демо-сайтов по ступеням цены ($20, $40, $70, $100, $200, $350). Открываются из блока «Сколько стоит сайт».
- `melty-bakery/`, `velora-clinic/` — ранние концепты.

Все компании, адреса, телефоны, цены и отзывы в демо вымышлены, на страницах они подписаны «Концепт».
